Schedule Helper – quick start

Keep this open on your phone while you work on the computer.

1. Load the week

  1. Post the schedule in HotSchedules, then download the Weekly Roster.
  2. In Chrome, click the S (Schedule Helper) button → Choose File → pick the roster.
  3. Check Week starting is the Monday, check names, untick anything that shouldn't go in.
  4. Use this schedule → Open Kronos → sign in → Schedule Planner.

2. Show me once (only the first time, or after an update)

  1. Helper box → Show me once → pick a shift without ⚠ → Start watching.
  2. On the grid, click the empty spot in that person's row, under that day. Box in the way? Press its – to shrink it.
  3. In the side panel: leave Regular, replace Start Time and End Time (Kronos puts in 1 hour), press Apply, then Save in the top bar.
  4. Helper: I saved it - done. Step 1 should say "the empty spot on the grid" with a ✓. The Apply click should be ticked Save / Apply button, with the top-bar Save after it → Save these steps.

3. Fill the week

  1. Auto-fill → Start. For each day: check the list → Add the ticked shifts.
  2. Hands off the mouse and keyboard while it works. Red Stop stops it any time.
  3. ⚠ job-change shifts (server on Bar): the first time, it asks you to show it how you change the job (usually Transfer Employee). Do it, don't press Save, then I changed it – done.
  4. When it's done, look over the week in Kronos.

If it gets stuck

  1. Can't find the person or day: scroll the grid so their row shows → Try again. Or click the spot yourself → I did it. Or Skip this shift.
  2. Warning "no name I can find again" / wrong person or day in Show me once: press debug export next to that step and send the file schedule-helper-debug.txt (in Downloads) to Joseph.
  3. Typed into the wrong box: Stop, delete that shift in Kronos, load page → Forget "Show me once", show it again.
  4. Prefer to do every click yourself? The Copy tab copies each value for you to paste.
Check with your manager that using the helper is OK. It never sees your password and nothing is saved in Kronos without you.
