# Programs

Stand-alone programs and mods, each in its own folder. To grab just one, open
the **Releases** page and download that program's zip. You don't need the rest
of this repo.

| Program | What it is | Download |
|---|---|---|
| [WoW Claude (MoP)](wow-claude-mop/) | Chat with Claude Code from inside World of Warcraft: Mists of Pandaria Classic | Release `wow-claude-mop-v1` |
| [Spire Recolor](sts2-recolor/) | Slay the Spire 2 mod: recolor or repaint characters and bosses, share looks with friends | Release `sts2-recolor-v1` |
| [Damage Meter](sts2-damage-meter/) | Slay the Spire 2 mod: Details!-style damage meter with Doom & Poison tracking and co-op support | Release `sts2-damage-meter-v1` |
| [PixelDex](pixeldex/) | Pokedex companion for Pixelmon Reforged: where to catch each Pokemon, biome browser, caught tracker | Release `pixeldex-v2.3.1` |
| [Schedule Helper](schedule-helper/) | Chrome extension: HotSchedules Weekly Roster into Kronos/UKG Schedule Planner (copy mode or auto-fill with approval) | Release `schedule-helper-v3.3` |
| [Card Art Pack](sts2-card-art/) | Slay the Spire 2: 180 custom card pictures (all Defect + Necrobinder cards) for the Card Art Editor mod | Release `sts2-card-art-v1` |
| [Gatcha Machine](gatcha-machine/) | Pixelmon add-on mod: earn points, case-opening spin for Rare/Epic/Legendary/Ultimate bosses | Release `gatcha-machine-v1.2` |
| [Biome Compass](biome-compass/) | Minecraft mod: Nature's Compass-style biome finder where you unlock biomes by visiting them, with shared compass groups and a Curios slot | Release `biome-compass-v1.8.1` |
| [Legendary Clock](legendary-clock/) | Pixelmon add-on mod: countdown to the next legendary and mega boss spawn try, the time of day it will be then, movable on-screen timer and a Curios slot | Release `legendary-clock-v1.1` |
| [Forage Station](forage-station/) | Pixelmon add-on mod: a block that holds a Pokémon from your party or PC and forages the biome on its own (Pixelmon's Forage items, faster with Speed), hopper-friendly storage | Release `forage-station-v1` |
| [Tabletop](tabletop/) | Browser tabletop: grid board with 3D minis, GM hosts and players join with a code; players move only their own mini, GM controls everything; physics dice, terrain, joinable boards, attachable any-size pieces, stats/movement range/initiative/line of sight/hidden areas for dungeon play, chat, map pictures, .glb models | [Play in the browser](https://xrunriot-wp.github.io/programs/tabletop/) |

The first four are Windows programs; Schedule Helper is a Chrome/Edge extension (no install, no .exe).
