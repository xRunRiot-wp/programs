# PixelDex Structure Overlay (Minecraft mod)

NeoForge 1.21.1 (21.1.x), tested with Pixelmon 9.4.1. Download `pixeldexoverlay-1.0.0.jar` from the `pixeldex-v2` release.

- Press **.** (period) to show / hide outlines of every structure within ~128 blocks, with names floating above them.
  Pixelmon structures (graveyards, haunted towers, temples, shrines, raid dens...) are gold, vanilla ones blue, other mods' white.
  The key can be changed in Options → Controls → Key Binds → "PixelDex Structure Overlay".
- Install: put the jar in the `mods` folder. It must also be on the server / the host's game (only the server knows where
  structures are). If a server doesn't have it, players can still join; the key just says it isn't installed there.
